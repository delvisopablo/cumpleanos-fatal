# Fotos durante las canciones

Guarda las fotos de cada persona en `assets/song-photos/<id>/` y añade sus rutas,
en orden, al campo `songPhotos` de `js/config.js`. Ejemplo:

```js
songPhotos: [
  "assets/song-photos/carlos/1.jpg",
  "assets/song-photos/carlos/2.jpg"
]
```

Las fotos se alternan suavemente mientras suena la canción. Una lista vacía o
una imagen ausente no bloquean la celebración.
