# Sonido de comer

Sube a esta carpeta el archivo `comer.mp3`:

```text
assets/sfx/comer.mp3
```

Cada mordisco reproduce el archivo completo y la animación del triángulo se
ajusta automáticamente a su duración real, leída desde los metadatos del audio.
Si el archivo falta o el navegador no puede reproducirlo, la web continúa con
un sonido sintetizado breve y una animación de un segundo.
