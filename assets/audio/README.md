# Canciones

Sube aquí el archivo `.mp3` de la canción de cada persona, con el mismo
nombre que aparece en el campo `audio` de `js/config.js`:

- `hungryman.mp3`
- `dientes.mp3`
- `carlos.mp3`
- `daviles.mp3`

En cuanto el archivo esté en esta carpeta con ese nombre exacto, sonará
automáticamente al soplar su vela — no hace falta tocar nada más.

Si quieres usar otro nombre de archivo, cambia también la ruta en el
campo `audio` de esa persona en `js/config.js`.
